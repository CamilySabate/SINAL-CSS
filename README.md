SINAL-CSS: Falha na Transmissão
Projeto desenvolvido para o trabalho de Desenvolvimento de Sistemas sobre Flexbox, do 1º ano E.

Sobre o projeto
O projeto aborda o funcionamento do CSS Flexbox, suas propriedades, aplicações práticas, acessibilidade e erros comuns.
A apresentação também inclui a dinâmica Falha na Transmissão, na qual os participantes devem identificar e corrigir erros em um código CSS, sem modificar o HTML.

Conteúdo
- História e evolução dos layouts CSS.
- Flex Container e Flex Items.
- Eixos principal e cruzado.
- Principais propriedades do Flexbox.
- Aplicações práticas e comparação com CSS Grid.
- Acessibilidade e erros comuns.
- Dinâmica de identificação e correção de erros em CSS.

Será utilizado:
- CSS3 (Flexbox)
